# 彰銓｜生產進度看板（腳輪廠）

把紙本「派工單」變成可即時查看的生產看板：廠內與業務同一畫面看到每張單的工序進度、交期風險與異常。

**線上看板**：<https://cceccecasters.github.io/caster-production-board/>

---

## 看板流程

```
備料／採購 → 沖壓 →〔特殊加工〕→ 電鍍 → 腳架組裝 → 成品組裝 → 檢驗 → 包裝出貨 → 結案
                        （條件式，一般件跳過）
支線：採購（輪子）─── 並行，終點是成品組裝
```

## 三條規則

| 規則 | 行為 |
|---|---|
| 輪子閘門 | 成品組裝完成 **且** 採購（輪子）完成，才放行檢驗 |
| 異常閘門 | 工序有「處理中」異常時，即使標記完成，卡片也不離開該階段 |
| 風險判定 | 逾期或預計完成晚於交期＝高；未結案異常、輪子未到、交期 ≤3 天＝注意 |

## 操作

- **＋ 新增派工單**：填規格與數量，工序日期依工時自動排到預計完成日
- **點卡片**：看規格、工序（未開始／進行中／完成）、異常與對策、物料委外、跟進紀錄
- **＋ 新增異常**：可切「處理中／已結案」，結案後卡片才會往下走

## 資料存放（重要）

目前是**示範版**：資料存在瀏覽器 `localStorage`，換電腦、換瀏覽器、無痕模式都看不到，也沒有多人同步。
正式上線要接 Google Sheets + Apps Script，欄位對照與 API 契約見 `即時看板_串接說明.md`。

## 檔案

| 檔案 | 用途 |
|---|---|
| `board.html` | 看板本體（單檔、無外部依賴、可離線開） |
| `index.html` | 根網址轉址到 `board.html` |
| `即時看板_串接說明.md` | Sheets 欄位對照、API 規格、閘門規則 |

## 更新方式

改 `board.html` 後 commit 並 push 到 `main`，GitHub Pages 約 1 分鐘後自動更新。

```powershell
git add board.html
git commit -m "update board"
git push
```
